# CortexLLMs

**Open-source LLM tools for building smarter AI applications.**

CortexLLMs is a collection of production-ready tools for working with Large Language Models (LLMs). We build open-source solutions for RAG, MCP agents, token compression, and AI orchestration.

## Our Projects

| Project | Description | Stars |
|---------|-------------|-------|
| [AgentForge-Platform](https://github.com/CortexLLMs/AgentForge-Platform) | Unified token compression engine combining multiple LLM optimization tools | ⭐ |
| [headroom](https://github.com/CortexLLMs/headroom) | Compress LLM outputs, logs, and RAG chunks — 20-95% fewer tokens | ⭐ |
| [fastmcp](https://github.com/CortexLLMs/fastmcp) | The fast, Pythonic way to build MCP servers and clients | ⭐ |
| [mcp-agent](https://github.com/CortexLLMs/mcp-agent) | Build effective agents using Model Context Protocol | ⭐ |
| [mcp-rag-skills-agent](https://github.com/CortexLLMs/mcp-rag-skills-agent) | Industrial AI agent combining MCP, RAG, and Skills execution | ⭐ |
| [rag-platform](https://github.com/CortexLLMs/rag-platform) | RAG Platform — FastAPI + Qdrant + Supabase + OpenAI | ⭐ |
| [ai-orchestration-mvp](https://github.com/CortexLLMs/ai-orchestration-mvp) | Local-first RAG pipeline with MCP and custom TCP sockets | ⭐ |
| [lasqAI](https://github.com/CortexLLMs/lasqAI) | Multi-model AI platform with comparative synthesis across LLMs | ⭐ |
| [morocco-economic-pipeline](https://github.com/CortexLLMs/morocco-economic-pipeline) | Morocco Economic Analysis Pipeline — ML/DL models | ⭐ |
| [gmail-ai-draft](https://github.com/CortexLLMs/gmail-ai-draft) | AI email assistant with automatic draft responses | ⭐ |
| [JobSeekerSkills](https://github.com/CortexLLMs/JobSeekerSkills) | 17 AI-powered skills for resumes and career development | ⭐ |

## Key Technologies

- **LLM Integration**: OpenAI, Anthropic, Meta, Mistral
- **RAG**: Qdrant, Supabase, vector search
- **MCP**: Model Context Protocol servers and clients
- **Token Compression**: Reduce costs by 20-95%
- **AI Agents**: Multi-agent orchestration

## Getting Started

```bash
# Install our most popular tool
pip install headroom

# Or build an MCP server
pip install fastmcp
```
